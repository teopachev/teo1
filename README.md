# teo1 — GymApp

App iOS de entrenamiento en SwiftUI con widgets (GymApp + GymWidgets).

- `GymApp/` — la app: modelos, vistas por funcionalidad y utilidades.
- `GymWidgets/` — widgets de pantalla de inicio y bloqueo.
- `WidgetShared/` — datos compartidos entre app y widgets.
- `deploy.sh` — compila e instala en el iPhone o en el simulador (`./deploy.sh sim`).
